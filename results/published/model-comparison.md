This document contains the recorded results from the original project experiment.

## Interpretation

The hybrid model achieved the highest recorded accuracy and F1 score. It combined manually engineered URL characteristics with signals generated by the fine-tuned DistilBERT model.

DistilBERT achieved the strongest recorded ROC-AUC and PR-AUC values. This suggests that the transformer model produced highly effective ranking scores, even though the hybrid classifier performed slightly better at the selected decision threshold.

The classical models provided lower-cost baselines that can be trained and evaluated substantially faster than the transformer-based approaches.

## Models Evaluated

### Classical URL-feature models

The project evaluates three tree-based classifiers trained on manually engineered URL features:

* Random Forest
* XGBoost
* LightGBM

The engineered features include URL length, character counts, path depth, subdomain count, IP-address usage, and suspicious keywords.

### Character n-gram baseline

The text baseline uses character-level TF-IDF features with logistic regression. Character n-grams can identify suspicious URL fragments without requiring manual parsing or transformer inference.

### DistilBERT

DistilBERT is fine-tuned directly on URL strings as a binary classifier. This approach attempts to learn structural and lexical patterns automatically.

### Hybrid model

The hybrid model combines:

* manually engineered URL features;
* the phishing-class logit produced by DistilBERT;
* the phishing probability produced by DistilBERT;
* a LightGBM classifier for final prediction.

## Evaluation Limitation

The original experiment combined a held-out subset of the primary dataset with an OpenPhish feed containing only phishing URLs. This provides useful information about phishing detection but changes the class distribution of the test set.

A future rerun should report at least two separate evaluations:

1. performance on the internal stratified holdout set;
2. phishing recall on the external OpenPhish feed.

This separation will make the results easier to interpret and reproduce.
